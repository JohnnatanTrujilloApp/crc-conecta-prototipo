# Requisitos y secuencia de entrega

El Documento Maestro CRC Conecta es la autoridad funcional del producto. El
desarrollo seguirá su orden incremental:

1. Sprint 0: infraestructura, calidad, Supabase, entorno y documentación.
2. Sprint 1: organizaciones, sedes, autenticación y personas.
3. Sprint 2: roles, permisos, alcances y RLS.
4. Sprint 3: familias, ministerios, perfil y búsqueda global.
5. Sprint 4: eventos, asistencia y dashboard.
6. Sprint 5: programas, módulos y lecciones.
7. Sprint 6: grupos, matrículas, sesiones y asistencia de clase.
8. Sprint 7: seguimientos, llamadas, visitas y dashboard de discipulado.
9. Sprint 8: reportes, exportaciones y auditoría.
10. Sprint 9: portal público, contenidos y SEO.

## Criterios transversales

Cada módulo debe contemplar carga, errores, validación, estado vacío, mensajes
claros, diseño responsive, permisos y auditoría cuando corresponda. No se
utilizará información personal real hasta que el aislamiento multi-sede y RLS
hayan sido implementados y probados.
